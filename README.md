# justinharty.com

Academic website of Justin S. Harty, PhD, LCSW (Arizona State University School of Social Work).

- Layout adapted from Yaoyao Liu's [Minimal Light](https://github.com/yaoyao-liu/minimal-light) Jekyll theme (CC0), restyled to ASU web brand standards.
- Publications, conferences, and presentations are generated from `_bibliography/cv.bib` by `scripts/bib2data.py`.
- See **HOW-TO-UPDATE.md** for adding papers, PDFs, slides, and posters.
- The previous al-folio version of this site is preserved on the `al-folio-archive` branch.

Build locally: `python3 scripts/bib2data.py && bundle exec jekyll serve`
